# Native clause corpus reference engineering

The [journal](journal.json) retains ten diagnostic attempts and their exact compressed files. These are controlled TypeScript Toolbox reference calls with TypeScript or Go storage, not native-wallet qualification. The final TypeScript and Go attempts independently replay to 132 PASS, 99 FAIL and one BLOCKED across 232 observations. Their original 42-method-boundary predicates all pass. All outer clients, services, overlay and Mongo processes close successfully.

The diagnostic sequence retained the following corrections:

- TypeScript attempt1 encountered evidence serialization of optional `undefined` properties; later evidence uses the actual JSON omission semantics.
- Attempts2–4 exposed stale certificate identifiers, reserved funds from accepted malformed calls, unsuitable input scripts, absent headers and incomplete positive controls. Later fixtures use fresh identifiers, public transaction batching cleanup, an executable OP_DROP/OP_TRUE input and the retained height1 fixture.
- Attempt5 removes those fixture blockers. Attempt6 adds consuming-method controls on separate fresh actions. The original Go attempt shows why retrying a consumed action cannot establish a positive control.
- The version-string oracle initially imposed an unsupported ban on hyphens in vendor names. TypeScript attempt7 and Go attempt3 execute after that correction and preserve the earlier failure evidence unchanged.
- Go retains an already-aborted response to cleanup after malformed `signAction.sendWith`; the cleanup error remains visible. It is not relabeled as a successful abort. Outer process cleanup succeeds.

Literal standard mismatches, including negative net `listActions.satoshis` against the positive source alias, reserved namespace behavior, malformed inputs and structured errors, remain observations. The result does not establish complete BRC-100 conformance or unsafe transaction values. Broader obligations stay explicit in the source profile.

These engineering runs occurred while the prospective corpus was under development. Their exact historical source identities were not frozen, and the journal makes no claim that a later source digest identifies an earlier diagnostic execution.
